# RRS 产品与 Agent 文案

本文案根据当前代码中的真实能力整理，可用于产品介绍、演示页、项目主页、Agent prompt、状态提示和发布说明。没有在代码中实现的能力不写入产品承诺。

## 产品定位

### 一句话介绍

RRS 是一个面向期刊编辑的审稿人推荐与证据复核工作台：从稿件解析开始，给出可解释、可追溯、需要人工确认的候选结果。

### 30 秒介绍

上传稿件后，RRS 先解析标题、摘要、关键词、作者和机构，再用稿件证据与审稿人论文库完成混合召回和重排。每位候选人都带有代表论文、检索路线、评分拆解和冲突风险。编辑可以用自然语言让编辑助手调整年份、领域、机构和数量约束，也可以生成邀请邮件草稿；涉及外部动作时，系统会停下来等待人工审批。

### 页面首屏

- 标题：**让审稿人推荐从“凭经验”变成“有证据的编辑决策”**
- 副标题：上传稿件，确认元数据，查看候选人和论文依据，再由编辑完成最终选择。
- 主按钮：**上传新稿件**
- 次按钮：**查看推荐依据**
- 信任提示：**证据优先；邮件只生成草稿，发送前必须人工确认。**

## 功能文案

### 稿件工作区

- 模块名：稿件队列
- 空状态：还没有稿件。上传 PDF 或 DOCX 后，从这里开始确认元数据。
- 解析说明：使用文档解析器提取结构化内容，并保留章节、页码和质量信号。
- 确认说明：标题、摘要、作者、机构和关键词会影响冲突过滤与推荐排序，请在运行推荐前复核。

### 混合推荐

- 模块名：推荐审稿人
- 说明：综合关键词、全文语义、论文元数据和近期发表信号，先过滤已知冲突，再返回可解释候选人。
- 结果提示：每个候选人都应有论文证据和评分拆解；排序分数用于比较候选人，不代表录用概率。
- 无结果：还没有推荐结果。先确认稿件标题和作者，再运行推荐。
- 降级提示：部分检索路线暂时不可用，当前结果仅基于仍然可用的证据，请复核降级原因。

### 证据抽屉

- 标题：论文证据复核
- 说明：查看代表论文、匹配关键词、文本重叠和本地证据片段。
- 全文提示：仅打开 DOI、OpenAlex 或明确标记为开放获取的 PDF；没有可验证全文时，请从论文详情页继续核对。
- 风险提示：外部论文信息来自公共数据源，需要结合 DOI、OpenAlex ID 或 ORCID 做身份和元数据复核。

### 编辑助手

- 标题：编辑推荐助手
- 说明：用自然语言调整领域、年份、机构、数量和冲突约束，并追问推荐依据。
- 首次引导：例如：推荐 5 位近三年研究 GraphRAG 的审稿人，尽量来自不同机构，并逐一说明依据。
- 投稿检查快捷语：检查稿件投稿信息和解析质量，列出缺失信息、证据位置及需要人工复核的事项。
- 推荐快捷语：先根据稿件证据确认研究主题，再推荐 5 位审稿人，尽量来自不同机构；逐一解释推荐依据和冲突检查的局限。
- 邀请快捷语：根据当前候选名单，为前 3 位审稿人准备邀请邮件草稿，只使用已有证据，不发送邮件。

## Agent 交互文案

### 状态

| 状态 | 推荐文案 |
| --- | --- |
| 已提交 | 已提交，等待执行 |
| 处理中 | 正在处理，可稍后回来查看 |
| 等待审批 | 以下操作需要你确认 |
| 已完成 | 本次执行已结束，请复核结果 |
| 预算结束 | 执行预算已用完，结果可能不完整 |
| 失败 | 本次未完成。请核对已有结果后再提交调整后的任务。 |
| 连接异常 | 暂时无法获取状态，后台任务可能仍在执行。请先刷新状态。 |
| 任务过多 | 当前任务较多，请稍后再试。 |

### 审批

- 审批前：该操作可能产生外部影响，请确认工具、参数和目标。
- 同意：同意上述操作
- 拒绝：拒绝并继续
- 草稿说明：这是邮件草稿，不代表已经发送；请确认收件人、证据和利益冲突后再使用。
- 未发送承诺：系统不会自动发送邮件。

### Agent 稳定上下文

以下句子可直接放入 Agent 的稳定上下文或技能说明中：

1. 先使用稿件和持久化推荐结果中的证据，再给出编辑建议；无法找到证据时明确说出缺口。
2. 将稿件原文、模型推断和外部学术数据分开表达；外部数据必须保留 DOI、ORCID 或 OpenAlex ID。
3. 利益冲突过滤是硬约束，相关性排序是独立步骤；不要用高相关性覆盖已知冲突。
4. ORCID 候选人需要编辑确认，不能因为姓名和机构相似就视为同一作者。
5. “没有发现撤稿记录”只表示当前数据源没有返回通知，不等于论文不存在完整性问题。
6. 邮件只生成草稿，不能声称已经发送；任何外部副作用都必须在人工审批后执行。
7. 达到轮数、工具数或上下文预算时，停止调用工具，基于已有证据给出带不确定性的最终答复。

## 对外发布短文案

### GitHub 描述

面向期刊编辑的审稿人推荐与证据复核工作台，内置混合 RAG、可解释推荐、LangGraph 编辑 Agent、学术 MCP 和人工审批流。

### 社交媒体短文案

RRS 把稿件解析、审稿人召回、论文证据和编辑助手放进同一条可追溯工作流。推荐结果带依据，邮件只生成草稿，外部动作必须人工确认。

### 演示开场

这不是一个替编辑做决定的自动发信器。它先把稿件和候选人的证据整理好，再把约束、风险和待确认事项交给编辑。
